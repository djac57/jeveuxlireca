🪜 Lecture Libre

Mon removepaywall perso — sans serveur, 100% dans ton navigateur.

1. Installe (glisse dans ta barre de favoris)

Fais glisser ce bouton dans ta barre de favoris (ou clic droit → Ajouter aux favoris) :

🪜 Lire sans mur

Bonus, pour les paywalls « durs » (texte pas chargé du tout) :

📰 Version archivée

2. Utilise

1
Sur un article bloqué, clique sur le favori 🪜 Lire sans mur.
2
Il retire le voile, le flou, le verrou de défilement et les fenêtres d'abonnement → le texte réapparaît.
3
Si l'article reste coupé (paywall « dur »), clique 📰 Version archivée.

🔐 Pourquoi c'est sûr

  • Aucun serveur : rien n'est hébergé, rien n'est exposé, rien à sécuriser.
  • Le code tourne uniquement dans ton navigateur, quand tu cliques, sur la page que tu lis.
  • Personne d'autre ne peut l'utiliser (contrairement à un proxy type Ladder qui, mal configuré, devient un relais ouvert sous ta responsabilité).

À savoir (honnête)

  • Marche très bien sur les paywalls « mous » (le texte est déjà chargé, caché sous un voile/flou — fréquent sur beaucoup de sites FR).
  • Ne peut rien faire si le texte n'est pas envoyé (paywall « dur ») → d'où le bouton Archivée. (Celui-ci envoie l'URL à archive.today, un tiers.)
  • Usage strictement personnel de lecture. Contourner un paywall peut enfreindre les CGU de l'éditeur.
